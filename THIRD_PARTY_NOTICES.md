## skills/nais-go-review

No sentence is copied. This package restates every rule in its own words, and
names its sources here because naming them is cheaper than checking whether a
paraphrase needed attribution.

- Go Code Review Comments, Test Comments and Effective Go. <https://go.dev>. Prose CC BY 4.0, code BSD, per <https://go.dev/copyright>. Attribution: Go Authors, CC BY 4.0.
- Google Go Style Guide. <https://google.github.io/styleguide/go/>. CC BY 3.0 Unported.
- Uber Go Style Guide. <https://github.com/uber-go/guide>. Apache-2.0.

The nais-specific rules come from `AGENTS.md` files across the nais org, which
Nav wrote. `nais/audit-approval` is an internal repository: its principles are
restated here, its repo-specific mechanisms and identifiers are not.
